## poker-solver
This repository contains an implementation of the Counterfactual Regret Minimization (CFR) algorithm, as introduced in the paper [Regret Minimization in Games with Incomplete Information](https://proceedings.neurips.cc/paper/2007/file/08d98638c6fcd194a4b1e6992063e944-Paper.pdf). CFR is a self-play algorithm for extensive games with imperfect information that iteratively minimizes *counterfactual regret* to approach a Nash equilibrium strategy in zero-sum games like poker.
